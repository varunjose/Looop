07 / FAQ

Questions,
answered.

Short answers about the loop, the oracle, and where the product stands.

Does a model decide whether the app is correct?

No. The model produces or repairs code. The oracle runs deterministic checks on the real artifact, and only those results can mark a run converged.

What happens when Looop cannot fix a failure?

It detects a stalled score or repeating failure fingerprint, stops the run, and escalates the evidence. Escalation means “stop spending,” not “fail louder.”

Why start from blueprints?

A blueprint materializes known-good structure and tests at zero token cost. The model works only in marked slots, reducing both risk and repair surface.

Is the engine tied to Cloudflare?

No. Packages in the core do not import Cloudflare. The engine is pure TypeScript and is designed to run across workerd, Node, and other compatible runtimes.

Is Looop ready for public live generation?

Not yet. The tested core is real, but auth, quotas, billing, abuse protection, and the full preview path still need to be completed before live mode is public.
