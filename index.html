FAQ

Questions,
checked.

Short answers, with the product claims kept honest.

How is Looop different from an AI code generator?

A generator produces an answer. Looop runs that answer through real typechecks, unit tests, and end-to-end checks, then repairs from the failures until it converges or knows to stop.

Does the model decide when the app is finished?

No. The model produces and repairs work. A separate verifier with no model call runs the checks and decides whether every blocking condition passed.

What happens when the loop cannot fix the app?

Looop detects a stalled score or a repeating failure fingerprint, stops spending, and escalates with the evidence instead of repeating until a hard step limit.

Can a later prompt break something that already passed?

The same workspace and its tests carry forward. A refinement that breaks an existing behavior fails the oracle and is repaired rather than silently shipped.

Can I use live generation today?

The simulation and core are useful today. Public live mode should wait for auth, quotas, billing, and abuse protection so the generation endpoint cannot become an unauthenticated model proxy.
